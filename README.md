# UCOS Architecture Registry

Central, evidence-driven registry for the Universal Content Operating System (UCOS).

Tracks 23 layers, responsibilities, functions, dependencies, contracts, data flow, integrations, verification, incidents, and changes.

Rules: no invented capabilities or metrics; status must be evidence-backed; production integrations are live only after real verification; UNKNOWN is preferred over guessing.

The main UCOS repository remains the implementation source of truth. This repository provides the architecture and verification registry.
